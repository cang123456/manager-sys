## 一、系统概述

### 1.1 一句话定位

一套基于 RuoYi-Vue v3.9.2（Spring Boot 3 分支）的**纯后端多模块后台管理脚手架**，开箱提供用户/部门/岗位/菜单/角色/字典/参数/公告八大系统管理能力、在线用户与日志监控、定时任务、代码生成器，并已基于其代码生成器扩展出「仓储物品(WMS)」示例业务模块。

### 4.2 数据权限范围（`sys_role.data_scope`）

| 取值 | 含义 | 过滤规则（`DataScopeAspect` 生成 SQL） |

| 4 | 本部门及以下数据权限 | `dept_id IN (SELECT dept_id FROM sys_dept WHERE dept_id = ? OR find_in_set(?, ancestors))` |
| 5 | 仅本人数据权限 | `user_alias.user_id = 当前用户 id`（未配置 userAlias 时不查询任何数据） |

> 其余安全处理：切面进入前清空 `params.dataScope` 防 SQL 注入；角色均不含目标权限字符时限制为不查询任何数据。

## 五、关键结论

1. **这是一套完整的企业级后台管理骨架**：以 `sys_menu` 为功能与权限的单一权威来源，通过「用户-角色-菜单-权限标识」四元模型打通了 **85 条菜单功能点 / 81 个权限标识 / 153 个后端接口功能点**，做到菜单、按钮、接口三级权限一致。
2. **八大系统管理 + 五大监控开箱即用**：用户/部门/岗位/菜单/角色/字典类型/字典数据/参数配置/通知公告 + 在线用户/定时任务/任务日志/操作日志/登录日志/服务监控/缓存监控/连接池监控，均具备「列表-详情-新增-修改-删除-导出」完整 CRUD 与状态变更。
3. **框架级公共能力非常厚实**：认证鉴权（JWT+Redis+权限注解+失败锁定+BCrypt）、数据权限（5 种范围 + `@DataScope` 切面已在用户/角色/部门落地）、操作日志 AOP、统一异常与响应、Excel 导入导出、通用文件上传下载、验证码、多数据源、XSS/CORS/国际化等，均可在其上直接开展业务开发。
4. **具备低代码/代码生成能力**：`ruoyi-generator` 支持数据库表导入、建表、字段配置、代码预览、zip 下载 / 生成到指定路径，并内置 **20 个 Velocity 模板**，可产出 Java（Controller/Domain/Mapper/Service/Impl）、MyBatis XML、Vue2/Vue3/Vue3-TS 页面、JS/TS API 与菜单 SQL，实现前后端一体化生成。
5. **已有一套可复用的自研业务范例（WMS 仓储物品）**：由代码生成器产出的 `wms_goods` 模块（6 个接口、14 个业务字段、含库存/预警/成本/售价等），验证了「生成器 → 业务模块」的落地链路；但该模块尚未纳入 `sys_menu` 初始化脚本与建表脚本。
