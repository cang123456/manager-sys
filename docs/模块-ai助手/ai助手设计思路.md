【错误原因】

因此流程是：

1. 模型给了一个不存在的路径
2. 我的校验认为“匹配到了”（其实匹配的是 404 兜底）
3. `router.push` 成功、地址栏变了
4. 内容区渲染成了 404 页，而你看到的是“没反应”

是ai的判断逻辑写错了，不是模型的问题。

改成了什么

| 原来                                 | 现在                                                         |
| :----------------------------------- | :----------------------------------------------------------- |
| 用 `matched.length > 0` 判断路径存在 | 用「注册表里有没有**完全相同**的 path」判断，兜底路由不会被误认 |
| 跳完不看结果                         | 跳完检查是否命中 `pathMatch` 兜底，命中就算失败              |
| 失败了也显示“已跳转”                 | **自动 `router.replace` 回滚**，不停在 404 页                |
| 报错只说“不存在”                     | 连带输出：已注册路由数、同名路径条数、**前 20 条注册路径样本** |

还加了一个「**再跳一次**」按钮：失败时点它，可以绕过模型、直接用上次的参数重试，省掉一次对话。

解决方案：

我做了一次对照实验，只改“发不发历史”，其他完全一样：

| 发给模型的内容             | 它回答的菜单                      |
| :------------------------- | :-------------------------------- |
| 不带历史                   | ✅ `/system/role` 角色管理         |
| 带一轮「用户管理」的对话   | ❌ `/system/user` 用户管理         |
| 只带用户的话、不带助手回复 | ❌ `/system/user`，还吐过非法 JSON |
| 历史压成 system 里一句背景 | ✅ `/system/role` 角色管理         |

**根因是我自己给模型看了一段假内容**：那句「好的，这就为你打开「用户管理」。」是我用前端模板生成的，不是模型说的。我却把它当成 assistant 的回复发回给模型，模型看到“自己上一轮说过用户管理”，就顺着重复了。

也就是说：**你在问角色管理，模型却在模仿一段我编出来的历史。**

改了什么

| 项             | 原来                      | 现在                                                       |
| :------------- | :------------------------ | :--------------------------------------------------------- |
| 请求内容       | system + 最近 10 条对话   | **只发 system + 你这一句话**                               |
| 上下文         | 成对的 user/assistant     | 压成一句 `背景：用户上一轮打开了 用户管理（/system/user）` |
| 参数为空       | 拼出「打开「undefined」」 | 提示「模型这次没给出具体页面，请再说一次」                 |
| 目标就是当前页 | 报红色“跳转失败”          | 提示「你已经在 X 页面了」                                  |
